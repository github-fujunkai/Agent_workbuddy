# AI 产品经理面试准备作战计划

> 基于《高频面试 245 题》+《知识星球 2.0》+ 你已有的转岗知识包，三者咬合方案。
> 一个核心判断先给你：**这两份资料不是让你从零学，是给你的知识包配上"题库坐标系"——你缺的不是知识，是每个考点对应的项目证据和逐字稿。**

---

## 一、先看清楚：出题人在考什么

博主自己在使用说明里写明了三条考察逻辑（这就是你的备考大纲）：

1. **AI PM 是否建立了自己的 SOP**：模型评测、意图优化、应用层设计——你全有（评测集/bad case 评审会/skill 设计）
2. **三大话题：RAG、提示词工程、Agent**——不考技术细节，但必须懂原理和运作方式——你的知识包在 Agent 和 prompt 上超配，**RAG 是唯一短板**
3. **传统 PM 基本功**：项目价值深挖、工作方法、项目管理、情商——和 AI 无关，但你前端出身做项目多年，缺的是"把经验翻译成 PM 语言"

## 三、核心打法：一个项目打通 130 题

博主的示范答案项目是"野外动植物 AI 监测"，和你的智慧仓储**几乎同构**——意味着他 245 题里所有示范逐字稿，你都能直接换弹药：

| 博主的示范 | 你的弹药 |
|---|---|
| 软硬件结合（野外相机+AI） | 软硬件结合（RFID+AGV+门禁+Agent） |
| SaaS + 涉密场景私有化部署 | 涉密内网私有化部署 |
| 端侧 AI 过滤减少 80% 人工筛查 | 盘点差异率 5%→0.8%，领用 15 分钟→40 秒 |
| LLM+RAG 受控 AI 助手 | Agent 自然语言 + RAG 三知识库 |
| BadCase 反哺迭代 | 周四 bad case 评审会 + 300 条评测集 |
| 沉淀 CV+大模型 SOP | 沉淀 skill 方法论 + 评测机制 |

**他的每一题"回答思路"，你都用"智慧仓储版"重写一遍，这就是你的题库。**

## 四、准备优先级

### P0 · 必练（70% 精力）：十道核心题逐字稿

每题 = 博主的回答套路 + 你的项目证据。前十道最高频，覆盖一半以上追问：

1. **介绍你做得最好的项目**（2 分钟版：三期规划+量化指标+三个冲突各一句）
2. **RAG 落地步骤 / 知识库怎么建**（你的三个知识库是弹药，但技术话术要补——见第五节）
3. **RAG 会怎么失效**（检索不到 / 检索到没用好 / 从上下文提取错——配你项目的排障问答例子）
4. **怎么降低大模型幻觉**（你的答案现成且高级：结构化输出+置信度三档+拒识+人工确认闸门+兜底规则）
5. **bad case 收集后怎么优化**（归因到层→改 description/补兜底/加 few-shot→评测集回归——你独有的机制化答案）
6. **怎么提升意图识别能力**（意图体系+三档阈值+别名字典+评测集迭代）
7. **评测集怎么建、怎么保证质量**（300 条全 bad case 沉淀、95% 发版闸门）
8. **模型选型怎么做**（三看一测：你的五段式答案直接用）
9. **微调 vs RAG 怎么选**（补课：RAG 40% / SFT 10% / 模型 40% 的影响占比结论）
10. **AI 产品 ROI 怎么算**（提质提效减负+成本控制；你的数字：领用 40 秒 vs 15 分钟）

### P1 · 应备（20% 精力）
- 方法论 38 题的答题套路过一遍（需求判断/优先级/数据驱动——前端经验换皮）
- 个人规划 16 题：**转岗叙事专项**（"前端→AI PM"讲成优势：懂实现边界+契约思维+离用户近）
- 谈薪 4 题：提前定口径

### P2 · 扫盲（10% 精力）
- 剩余题目读一遍博主的"回答思路"，混个脸熟即可

## 五、补课清单：知识星球阅读地图（唯一短板）

按需精读，只补你缺的（其余章节你已超配）：

| 补什么 | 在知识星球哪节 | 为什么 |
|---|---|---|
| **RAG 全流程** | 分块策略 / Embedding / 检索召回评估 / Rerank / RAGAS 评测 | 你项目有 RAG 知识库，但技术话术没准备——这是 62 题里被问最多的 |
| **幻觉四类型与治理** | "降低大模型幻觉"相关节 | 配上你的确认闸门答案，秒变高分 |
| **提示词工程理论** | CoT 思维链 / few-shot / Reflexion | 你有实操手册，补理论名词 |
| **AI 产品 4 层架构** | 数据算力算法层/模型层/应用层/用户层 | 和你的五层架构合并成组合答案（一个是系统视角，一个是模型能力视角） |
| **训练常识** | SFT / 奖励模型 / PPO / GRPO | 听懂名词即可，面试能接话不露怯 |
| **Token/算力成本** | 算力章节 | 回答 ROI 题时的加分项 |

## 六、245 题使用方法：三遍法（博主原话：背题过不了）

- **第一遍 · 排雷**：只看题不看答案。能脱口而出的打勾（预计：AI 技术类过半能答）；答不出的标记
- **第二遍 · 换弹药**：看博主的回答套路，把每个套路翻译成智慧仓储版——套路是他的，证据是你的
- **第三遍 · 模拟**：脱稿讲。找我做模拟面试官，一轮 AI 技术专场、一轮项目深挖专场

## 七、14 天作战计划

**第 1 周 · 弹药生产**
- Day 1-2：项目 2 分钟 / 5 分钟版逐字稿（基于故事版改写成面试口径）
- Day 3-5：P0 十题逐字稿，每天 2 题
- Day 6-7：补课清单前四项（RAG 全流程 + 幻觉 + 提示词理论 + 4 层架构）

**第 2 周 · 实战化**
- Day 8-9：知识星球剩余补课 + 245 题第一遍排雷
- Day 10-12：245 题第二遍换弹药（重点：方法论 38 题 + 个人规划 16 题）
- Day 13-14：模拟面试两轮 + 谈薪口径 + 复盘查漏

## 八、三道你已经能秒杀的题（举例验证）

- **"你对 claude skills 怎么看，和 MCP 什么区别？"**（金蝶云真题）——你写过 skill 四层结构，还懂 MCP 是工具接口协议、skill 是业务流程约束包，这题能讲出面试官没听过的深度
- **"agent 回答边界用什么方案？"**（美团真题）——你的答案：感知层拒识 + skill 负面边界 + 兜底规则 + 确认闸门四道围栏，全是实战细节
- **"评测怎么判断是 prompt 问题还是基座发散？"**（真题）——你的归因到层机制 + 评测集回归就是标准答案
