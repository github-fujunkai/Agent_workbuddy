## 四、面试中：答题检查卡（心里过，不掏出来）

**每答一题前 3 秒自检**

- [ ] 这是座冰山——他的完整问句是哪 5-6 个子问题？
- [ ] 六环备齐了吗：结论 → 为什么 → 演进 → 证据 → 分工 → 价值
- [ ] 90 秒给链留钩子，不背长篇

**听不懂隐含问题时的补救话术**

- 答短了发现面试官没接话 → 主动补链："这个数字我再多说一句它的来历……"
- 被问懵 → 结构化兜底："这个我没直接做过，但我按 XX 框架想的话，第一……您看这个思路对吗？"——**诚实+思考框架 > 硬编**
- 数字被挑战 → "这个数我可以回去核实精确值，但量级和测算逻辑是这样的……"

**红线**

- [ ] 不贬低前雇主/同事
- [ ] 不把"我不会"说成"不知道"，说"这块我的做法是……"
- [ ] 军队项目涉密脱敏（见上）

## 五、反问面试官清单（挑 2-3 个问，全是加分项）

1. "团队现在的 Agent 落地到什么阶段了？评测体系是怎么搭的？"——探成熟度，也暗示你有评测意识
2. "这个岗位过去半年最头疼的 bad case 是什么？"——问出面试官的真实痛点
3. "PM 和算法/研发的协作边界在团队里是怎么划的？"——呼应你"标准归 PM、实现归算法"的方法论
4. "团队现在 RAG 还是 Agent 为主？数据资产的积累到什么程度了？"
5. "如果我入职，前 90 天您希望我先啃下什么？"

**别问**：加班多不多、福利怎么样（留给 HR 轮或 Offer 后）。

## 六、面试后 30 分钟复盘（每次面试都是排雷）

- [ ] 被问懵的 3 道题记下来（原话 + 我的回答 + 卡在哪）
- [ ] 追问暴露的知识缺口 → 加进补课清单
- [ ] 被挑战的数字 → 核实真实值
- [ ] 表现好的回答 → 固化进逐字稿
- [ ] 全部更新回《隐含问题解码-答题展开训练手册》——**复盘不过夜**
